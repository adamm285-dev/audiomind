# AudioMind Antigravity Plugin

This folder packages **AudioMind** as a self-contained Antigravity plugin (`plugin.json`, `mcp_config.json`, `skills/audiomind/SKILL.md`, and `assets/logo.svg`).

## Local Installation
Copy (or symlink) this `plugin/` directory to:
- **Windows**: `%USERPROFILE%\.gemini\config\plugins\audiomind\`
- **macOS / Linux**: `~/.gemini/config/plugins/audiomind/`

Then enable **audiomind** in Antigravity's **Customizations -> Plugins** page.
